# TechNova Responsive Landing Page

## 📌 Project Overview

This project is a responsive landing page created as part of the
Auspify Technologies Frontend Developer Internship.

The website demonstrates the use of HTML5 and CSS3 to create a
modern, responsive, and user-friendly landing page.

## 🚀 Features

- Responsive navigation bar
- Hero section
- Call-to-action buttons
- About section
- Services section
- Contact call-to-action section
- Responsive design for desktop, tablet, and mobile devices
- Hover effects and CSS transitions
- Semantic HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## 📱 Responsive Design

The website has been designed to adapt to:

- Desktop screens
- Tablet screens
- Mobile devices
